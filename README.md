## Stuff
- **Cava** - Music visualizer
- **Fastfetch** - System info in terminal
- **Matugen** - Wallpaper color sync
- **Rofi** - App launcher
- **SwayNC** - Notification center
- **Waybar** - Status bar for Hyprland
- **Waypaper** - Wallpaper manager
- **wlogout** - Logout/shutdown menu
